2. Cấu tạo từ / Dạng của từ (Word Formation)

Động từ (Verb) Danh từ (Noun) Tính từ (Adjective) Trạng từ (Adverb)
— music / musician musical (thuộc âm nhạc) musically
— art / artist artistic (thuộc nghệ thuật) artistically
perform (biểu diễn) performance / performer performing —
compose (soạn nhạc) composition / composer composed —
paint (sơn, vẽ) painting / painter painted —
differ (khác biệt) difference (sự khác biệt) different (khác biệt) differently

3. Phân biệt các từ dễ gây nhầm lẫn (Confusing Words)

✦ LIKE vs. AS

LIKE (Giới từ so sánh tương đồng): Giống như (so sánh diện mạo, hành động tương tự): 'She sings like an angel.'
AS (Giới từ chỉ chức năng / vai trò): Với tư cách là: 'He works as a music composer.'

✦ MUSIC vs. SONG vs. TRACK

MUSIC (Danh từ không đếm được): Âm nhạc nói chung (classical music, pop music).
SONG (Danh từ đếm được): Bài hát có lời (a beautiful song, write songs).
TRACK (Danh từ đếm được): Bản nhạc/bài hát trong một đĩa nhạc hoặc album.

4. Ngữ pháp: Các cấu trúc So sánh (Comparisons)

A. SO SÁNH BẰNG & KHÔNG BẰNG (AS ... AS / NOT AS ... AS)

• Khẳng định: S1 + V + as + adj / adv + as + S2
Ví dụ: This portrait is as colorful as that one.

• Phủ định: S1 + V(phủ định) + as / so + adj / adv + as + S2
Ví dụ: Modern pop songs are not as melodious as traditional folk songs.

B. SO SÁNH GIỐNG NHAU (THE SAME AS) & KHÁC NHAU (DIFFERENT FROM)

• The same as (giống như): S1 + V + the same (+ noun) + as + S2
Ví dụ: My favorite musical instrument is the same as Lan's.

• Different from (khác với): S1 + V + different from + S2
Ví dụ: Life of an artist is quite different from that of an engineer.

5. Ngữ âm: Âm /ʃ/ và Âm /ʒ/

Âm /ʃ/ (vô thanh)
musician, exhibition, machine, special, sugar, show, brush, traditional.
Âm /ʒ/ (hữu thanh)
pleasure, usual, leisure, television, decision, measure, conclusion, vision.
